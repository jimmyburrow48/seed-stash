# Seed Stash

A one-file clicker for hamsters with ambition. Tap the hamster to collect seeds, buy helpers that work while you're away, and watch the stash grow.

- **Tap** the hamster for seeds (more with "Bigger cheek pouches").
- **Helpers** earn seeds per second. Prices rise with every purchase.
- Progress saves in your browser's local storage.

Live: https://seed-stash.vercel.app (once deployed)

Open `index.html` in any browser. No build step, no dependencies.
